# 缓升缓降功能现状与待办

## 当前版本定论

- 本版本优先支持 BCX（宝辰鑫）内控缓降；SUP（超强伟业）继续沿用现有脚本，不在本次重写。
- BCX 的焊接、开光、关光功率单位均为 W，数值必须小于激光器峰值功率。
- BCX 缓升时间及由 `craftLeadOutRampDistance / craftWeldingSpeed` 换算出的缓降时间上限为 9999 ms。
- BCX 在降功率点关闭 CO1，由焊板使能下降沿触发内部缓降。
- BCX 送丝焊同时控制 CO2：起弧时先开 CO0，再连续开启 CO2、CO1；缓降点连续关闭 CO2、CO1；自融焊不输出 CO2。
- `craftLeadOutRampDistance > 0` 时，末段直线或圆弧在降功率点拆成两段；等于 0 时不拆轨迹，在焊接终点关闭使能。
- `craftRetractionDistance` 暂时保留 ABI 字段，但不再参与缓降距离和时间计算；上层应传 0。
- 轨迹模拟不下发激光器、送丝机参数，也不输出起收弧及缓降控制。

## 后续必须完成

1. 增加工艺级“内控/外控”模式字段，并定义旧结构体、旧 API 的兼容默认值。
2. 重写外控缓升缓降状态机：按固定周期更新峰值功率和送丝速度，处理写入失败、超时、取消和收弧抢占。
3. 外控模式下，将焊板缓升功率、缓升时间、缓降功率、缓降时间全部写 0，避免板卡内控与 SDK 外控冲突。
4. 将 SUP 现有 `slow_arc_start/slow_arc_stop` Lua 逻辑迁移到品牌策略，明确 0x0231～0x0234 的百分比和 3000 ms 上限。
5. 增加脚本快照测试，至少覆盖 BCX 送丝焊、自融焊、直线/圆弧、缓降距离为 0/正数、轨迹模拟和工艺切换。
6. SDK 不承诺多焊机并发；在公开 API 文档中明确同一进程禁止并发生成或下发多焊机脚本，并逐步消除全局脚本缓存。
