# SDK 外控功率与送丝阶段

## 启用方式与兼容边界

- 通过 `cl_ramp_control_config_set()` 显式启用，配置为 `LaserRampControlConfigSdk`，填写结构大小和 `LASER_RAMP_CONTROL_CONFIG_VERSION_SDK` 并检查返回码。
- 配置包含 `enabled`、`updatePeriodMs`、`settleTimeMs`、`timeoutMs`，按焊机句柄保存；改变配置后重新生成并加载程序。
- 当前覆盖宝辰鑫、超强 SUP26AD 和旧版超强自由通信协议；其他型号启用时明确返回能力错误。
- 旧调用方缺省保留原行为，不扩大 `MachineResource`、`CraftInfoLaserSdk` 的 ABI 布局。新模式三档送丝输入统一为 mm/s，超强在出口转换为 cm/min；禁用时保留旧接口原生单位。
- 功率曲线只使用实际出光的动态工艺通道，不逐周期修改设备额定功率。

## 板卡配置与执行顺序

- 同一个 Lua 阶段任务计算功率、送丝目标，时间源为控制器 `get_systime()` 返回的上电秒、微秒。
- 板卡缓升、缓降时间写 0；超强开关光百分比写 100，宝辰鑫绝对功率端点保留起弧、收弧 W 值。不能将所有品牌的四项开关光参数一律清零。
- 准备：设置初始功率和速度，完成必要的参数、串口帧准备后开启自动送丝和出光。
- 焊接送气由设备自动管理。SDK可按原协议下发送气工艺参数，但不独立操作气阀、不额外等待前送气或后送气时间。
- CO0 是红光开关及上层焊机使能总控，默认开启；通讯异常时原有上层使能链路关闭 CO0。正式焊接只控制 CO1；新模式的起弧、收弧、暂停恢复及异常停止均不操作 CO0，不替代上层联锁。
- 开光：起弧功率、起弧送丝速度按同一进度升至焊接值，不补发过时目标。
- 关光：从 SDK 合成降功率点启动缓降，继续末段直线或圆弧；此处不停丝、不回抽。
- 终点：取消旧任务，结束光和丝输出，正常停丝只提交一次；不得保持出光、正向送丝驻留等待剩余坡度。
- 旧自由通讯必须保护共用发送缓冲；取消任务不代表串口在途帧已经结束。终点先关光，再按发送截止时间提交停丝，不突发补写功率、速度帧。
- 旧自由通讯优先保证轨迹终点关光停丝；若最后一档收弧功率或丝速仍未发送，终点会取消该档，不能承诺精确到达设置的收弧值。映射协议在终点写精确目标后截止；串口末档精度需要结合发送预算另行优化。
- 暂停先保存当前阶段、目标及剩余时间，再取消任务和关闭输出；普通继续通过同一阶段控制器、新代次显式恢复，不直接复活旧任务或套用旧事件的开光指令。停止、正常结束及异常清除恢复资格。

## 停丝、回抽与自融焊

- `craftRetractionDistance` 仅保留兼容布局，按 0 使用；关光时间为完整 `craftLeadOutRampDistance * 1000 / craftWeldingSpeed`。
- 回抽长度、补丝长度、补丝延时和断丝模式保持各自含义，不因删除提前回抽距离而清零。
- 对停丝自动回抽的设备，只关闭自动送丝信号，让设备执行已配置的回抽、补丝，不重复发手动反转。
- 通讯回执不是机械动作完成反馈，未提供设备完成状态时不能宣称确认了回抽或补丝完成。
- 自融焊只执行功率阶段，不访问送丝参数、CO2、送丝通讯或回抽补丝。
- 轨迹模拟不加载外控运行时、不输出设备动作，也不取消正在运行的实焊阶段。

## 上层接入与周期

- 焊接前在后台读取实际通讯类型、目标从站及映射，核对功率、速度写块，再安装 SDK 配置；不要在 GUI 线程新增机器人配置查询。
- `scanTime` 不单独证明目标写块实际更新间隔，也不能未经调度依据直接乘映射段数。
- `updatePeriodMs` 是目标发布周期，`settleTimeMs` 用于准备和串口帧间稳定，`timeoutMs` 限制等待；它们不等于设备端实时同步或执行确认。
- 普通与 slow 接口复用同一运行时。旧超强手动点焊通过 `cl_craft_arc_script_get()` 使用当前工艺快照，不临时修改全局机器资源；点焊松开后通过 `cl_ramp_wait_phase()` 等待本次收弧阶段结束，再停光、停丝。等待被终止或新周期抢占时不得继续执行旧收尾。
- 宝辰鑫、SUP26AD 原生手动点焊保留板卡内控路径；SDK 外控启用后，进入原生手动会话需恢复所选工艺的焊接峰值、起收功率、渐变时间及填丝自动送丝设定。它们不通过 SDK 共同阶段任务实现手动变速。
- 原生手动切换工艺需重新准备后台会话；没有有效工艺时保留检气和独立手动抽送丝，不沿用未知的板卡参数启动点焊。恢复参数只留出后台通讯刷新时间，不等于设备完成反馈。
- 自动焊以轨迹终点约束停丝；距离除以设定速度仍是时间模型，速度倍率和加减速引起的偏差需要实机验证。

## 验证与设备确认边界

回归覆盖配置兼容、静态与动态单位、共同曲线、零及短时长、抢占和取消、自动送气不增加SDK等待、串口缓冲、终点幂等，以及填丝、自融和模拟。生成 Lua 在虚拟控制器执行验证，不替代设备验收。

实机仍需确认热改功率和速度、板卡零时间端点对动态功率的影响、目标写块延迟和抖动、品牌门控及自动回抽行为、机械动作完成反馈、暂停续焊联动。SDK 不承诺多焊机并发生成或执行共享脚本。
